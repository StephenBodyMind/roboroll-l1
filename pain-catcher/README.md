# Capture the Pain Point

An English-language mobile reflex game inspired by the RoboRoll app's pain-point capture feature.

The roller moves continuously along the back. When the body reacts and a pain point appears, the player must stop the roller as close to the target as possible. The game measures position error, reaction time, and combo performance across five rounds.

## Play locally

Open `index.html` through any static web server. No build step or external dependency is required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then click **Save**.

GitHub will publish the game at:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Controls

- Mobile: tap the large button or game area.
- Desktop: click or press `Space` / `Enter`.

## Gameplay

- Five rounds per challenge
- Randomized pain-point position and timing
- Position error measured on a simulated 60 cm track
- Reaction-time and combo bonuses
- Early-tap penalty
- Final S/A/B/C rank and shareable score

## Product connection

The game is a simplified interactive demonstration of the RoboRoll concept: capture the moment discomfort occurs and record the corresponding location on the body.
